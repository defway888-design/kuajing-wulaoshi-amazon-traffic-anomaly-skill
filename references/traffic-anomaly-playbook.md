# 吴老师亚马逊父商品流量异动分析 Playbook

## 1. 核心业务口径

本 Skill 只拆解流量异动，不处理转化率异动。转化率相关因素如 Coupon、价格、Review、购物车、竞品截流、页面转化力等，必须留给独立转化率 Skill。

分析对象固定为父商品。用户输入子 ASIN 时，先通过领星 MCP 找到父 ASIN；如果无法通过领星确认父 ASIN，停止分析并说明原因。父商品下的子体范围使用本月子体和上月子体的并集。

最终输出只保留命中的可能因素，不区分可控因素和不可控因素，不输出优化建议。

正式运行必须先读取并执行 `fixed-mcp-runbook.md`。该文件中的 MCP、工具/数据库、参数、字段和阻塞条件是固定执行标准，不允许临场替换或重新设计。

## 2. 市场与时间口径

### 2.1 市场

- 用户指定市场时，只分析该市场。
- 用户未指定市场且同一 ASIN 命中多个市场时，要求用户选择市场或明确选择“全部市场”。
- 用户选择“全部市场”时，逐市场独立分析与输出，不合并美国、加拿大或其他站点数据。

### 2.2 时间

- 完整月份分析：当前分析月 vs 上一个自然月。
- 当前分析月尚未结束：当前月已发生区间 vs 上月同等天数。
- 例：7 月 1 日做 7 月分析时，对比 7 月 1 日 vs 6 月 1 日。
- SIF 自然搜索相关数据优先按 month 做完整月对比。当前月未结束且 SIF 不支持自定义日期时，使用 latelyDay=30、latelyDay=7 或最近完整周作为替代口径，并在证据中说明替代口径。
- Listing 状态异常/被抑制只返回当前查询状态，不做时间对比。

### 2.3 变化判断

不设置变化阈值。当前值大于上期值即增加，当前值小于上期值即减少，当前值等于上期值即不命中。

## 3. 数据来源规则

最终输出的数据来源只保留 MCP 级别：

- 领星 MCP
- 卖家精灵 MCP
- SIF MCP
- 互联网搜索

不要在最终结论输出中写具体数据库、接口名、字段名或计算方法。内部分析必须使用 `fixed-mcp-runbook.md` 写死的工具和字段；输出只给用户看业务证据。

最终输出的数据证据必须具体量化。不得只写“当前期高于上期”“当前期低于上期”“有增加”“有减少”等泛泛表述；必须写出上期值、当前期值、变化值、变化率，或可核验的日期、数量、链接。

用户上传到 GitHub 的 Skill 包不得包含任何 MCP Key、secret-key、token、cookie、账号密码或本地私密配置。README 只能提供用户自行配置 MCP 的说明。

## 4. 全量验证闸门

正式运行时必须验证全部因素：

1. 父商品与市场确认
2. 流量异动方向确认
3. 当前父子体库存状态
4. 历史到货 / 断货
5. 广告花费增加 / 减少
6. Deals 促销开始 / 结束
7. 站外推广开始 / 停止
8. 变体增加 / 拆分
9. Listing 状态异常 / 被抑制
10. 自然搜索关键词排名上升 / 下降
11. 自然搜索关键词数量增加 / 减少
12. 主要关键词搜索趋势上升 / 下降
13. 联盟客推广 / 停止

只有以上全部验证项都完成，才能输出“可能的因素”。如果任一项未完成，禁止输出结论，必须输出阻塞项。

## 5. 因素验证逻辑

### 5.1 到货 / 断货

数据来源：领星 MCP。

父商品断货和到货必须使用父商品口径历史对比：

- 上月父商品 FBA 可售库存 = 0，本月父商品 FBA 可售库存 > 0，命中“到货”。
- 上月父商品 FBA 可售库存 > 0，本月父商品 FBA 可售库存 = 0，命中“断货”。
- 两期都 > 0 时，不命中到货/断货；库存减少不能直接归因为断货。

部分子体断货单独判断：

- 只检查当前在售子体。
- 任一在售子体 FBA 可售库存为 0，可标记为“部分子体断货”。
- 部分子体断货不等于父商品整体断货。

库存因素通常只解释同方向流量变化：

- 到货支持流量增加。
- 父商品整体断货或部分子体断货支持流量减少。

### 5.2 广告花费增加 / 减少

数据来源：领星 MCP。

广告花费按父商品下全部子体汇总。当前期广告花费 > 上期，命中“广告花费增加”；当前期广告花费 < 上期，命中“广告花费减少”。

广告只考虑花费因素，不在本 Skill 中拆预算、竞价、广告结构、点击率或转化率。广告花费增加支持流量增加，广告花费减少支持流量减少。

### 5.3 Deals 促销开始 / 结束

数据来源：卖家精灵 MCP。

只判断 Deals，不判断 Coupon。Coupon 属于转化率 Skill。

父商品下任一子体在分析期存在 Deal 价格大于 0，即判断父商品存在 Deals。Deal 价格为 -1 或无有效 Deal 价格时，不判断存在 Deals。

- 上期无 Deals，当前期有 Deals，命中“Deals 促销开始”。
- 上期有 Deals，当前期无 Deals，命中“Deals 促销结束”。

Deals 开始支持流量增加，Deals 结束支持流量减少。

### 5.4 站外推广开始 / 停止

数据来源：互联网搜索。

搜索父 ASIN、子 ASIN、品牌词、产品词、折扣词、deal、promo code、coupon code、Facebook、TikTok、YouTube、Instagram、Reddit、deal site 等组合。

命中必须同时满足：

- 至少找到 1 条可访问链接。
- 页面内容命中 ASIN、品牌或产品词。
- 页面时间落在分析区间内。
- 能判断推广类型。

站外推广是运营主动行为，例如品牌官方账号、官方活动页、主动联系的社群或 Deal 站投放、可确认的主动折扣码传播。站外推广开始支持流量增加，站外推广停止支持流量减少。

如果只能确认有外部链接但无法判断主动推广或联盟客自发推广，输出为“站外来源未判定”；如果最终输出只保留命中因素，证据不足时不要输出。

### 5.5 变体增加 / 拆分

数据来源：卖家精灵 MCP；父子关系仍以领星 MCP 为准。

对比父商品在当前期与上期的子商品数量或变体数量：

- 当前期数量 > 上期，命中“变体增加”。
- 当前期数量 < 上期，命中“变体拆分/减少”。

变体增加通常支持流量增加，变体拆分/减少通常支持流量减少。

### 5.6 Listing 状态异常 / 被抑制

数据来源：卖家精灵 MCP。

只能使用 `fixed-mcp-runbook.md` 指定的卖家精灵 MCP 字段判断 Listing 状态，不允许用领星 Listing 状态替代本项验证。

Listing 状态异常与断货分开判断。断货已经在库存因素中处理，不要把断货造成的不可售重复归因为 Listing 被抑制。

Listing 状态只查询当前状态，不做历史时间对比。任一子体出现异常，即标记父商品 Listing 存在异常，并输出异常子体数量或 ASIN 示例。

Listing 状态异常通常只支持流量减少；流量增加场景下不要输出该因素。

### 5.7 自然搜索关键词排名上升 / 下降

数据来源：SIF MCP。

验证 ASIN 在自然关键词下的自然排名变化。优先使用父商品/Listing 口径；如果 SIF 工具只接受子 ASIN，则先由领星 MCP 取得父商品下子体，再以该父商品下的子 ASIN 调用 SIF，并在内部维持父商品口径。

- 自然关键词排名整体上升，支持流量增加。
- 自然关键词排名整体下降，支持流量减少。

搜索结果页版位变化不单独作为因素，归入自然搜索关键词排名变化。

### 5.8 自然搜索关键词数量增加 / 减少

数据来源：SIF MCP。

验证父商品自然关键词覆盖数量。例如上期由 50 个自然关键词组成，当前期只有 30 个自然关键词组成，则自然搜索流量入口减少。

- 当前期自然关键词数量 > 上期，命中“自然搜索关键词数量增加”。
- 当前期自然关键词数量 < 上期，命中“自然搜索关键词数量减少”。

### 5.9 主要关键词搜索趋势上升 / 下降

数据来源：SIF MCP。

先用 SIF 识别父商品主要关键词，再查看这些关键词在当前期与上期的搜索趋势。主要关键词可优先选择流量贡献较高、自然相关度较高、排名靠前或业务上已指定的关键词。

- 多数主要关键词搜索量上升，命中“主要关键词搜索趋势上升”。
- 多数主要关键词搜索量下降，命中“主要关键词搜索趋势下降”。

类目大盘流量不做判断。亚马逊主要以搜索流量为主，本 Skill 不使用无法稳定量化的类目流量。

### 5.10 联盟客推广 / 停止

数据来源：互联网搜索。

抓取流程与站外推广相同，但分类不同：

- 站外推广：运营主动投放或主动联系渠道。
- 联盟客推广：联盟客、网红、内容站、测评站、导购站等第三方自发推广。

能确认第三方自发推广且时间落在分析区间内时，命中“联盟客推广”。能确认该推广停止或消失且与流量下降同向时，命中“联盟客推广停止”。

## 6. 禁止残留逻辑

不要输出或使用以下逻辑作为独立流量原因：

- 转化率异常、CVR 异常、价格、Review、星级、购物车、配送时效等转化因素。
- Coupon 促销。
- 类目大盘流量上涨/下滑。
- 竞品动作导致流量被分走或释放。
- 亚马逊搜索结果页版位变化。
- 优化建议、运营动作、恢复方案。
- 可控因素/不可控因素分组标题。
- 未命中的排查项。
- 未完成全量验证时输出“可能的因素”。
- 将 B 软件 MCP 的数据当作 A 软件 MCP 的替代数据。

## 7. 最终输出证据规则

最终输出面向运营人员，不面向数据工程人员。内部验证可以使用 MCP 字段，但输出给用户时必须翻译成自然语言，不得展示字段名、字段表达式、等号判断或接口计算过程。

各因素的数据证据必须达到以下颗粒度：

- 广告花费：写明上期花费、当前期花费、变化金额、变化率、币种；不能只写“父商品下全部子体广告花费汇总低于上月”。
- 到货 / 断货：写明父商品子体总数、无可售库存或恢复可售库存的子体数量、影响日期或天数、上期对照；只能用“无可售库存”“恢复可售库存”“部分子体断货”等业务语言。
- Deals 促销：写明上期与当前期是否存在 Deals、涉及子体数量、Deal 日期或天数、Deal 价格区间；不能只写“检测到 Deal 字段”。
- 站外推广 / 联盟客推广：写明可访问链接、页面日期、渠道类型、命中的 ASIN/品牌/产品词、推广是开始、持续还是停止。
- 变体增加 / 拆分：写明上期变体数、当前期变体数、变化数量、变化率。
- Listing 状态异常：写明当前异常子体数量、异常状态的自然语言描述、父商品总子体数；不要把断货重复写成 Listing 异常。
- 自然搜索关键词排名：写明关键词、上期自然排名、当前期自然排名、排名变化；如果是多关键词汇总，写明上升/下降关键词数量和代表关键词。
- 自然搜索关键词数量：写明上期关键词数量、当前期关键词数量、变化数量、变化率。
- 主要关键词搜索趋势：写明关键词、上期搜索量或趋势值、当前期搜索量或趋势值、变化量、变化率；如果是多关键词汇总，写明上升/下降关键词数量和代表关键词。

如果某个命中因素拿不到上述最小证据颗粒度，即使方向看起来一致，也不得输出该因素；应将该验证项视为未完成并输出阻塞模板。

## 8. 输出模板

```text
流量异动方向：流量增加

可能的因素：

1. 广告花费增加
   数据来源：领星 MCP
   数据证据：2026-05 广告花费为 364.95 美元，2026-06 广告花费为 424.90 美元，增加 59.95 美元，增幅 16.43%。
   可能原因：广告花费增加，带来更多广告侧流量。

2. 自然搜索关键词数量增加
   数据来源：SIF MCP
   数据证据：2026-05 自然关键词数为 348，2026-06 自然关键词数为 361，变化 +13，变化率 +3.74%。
   可能原因：自然关键词覆盖数量增加，父商品获得更多自然搜索流量入口。
```

如果没有因素命中：

```text
流量异动方向：流量减少

可能的因素：无
```
